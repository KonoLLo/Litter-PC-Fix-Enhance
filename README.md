# 小小PC-修复增强 / Litter-PC-Fix-Enhance

基于原「小小PC」模组的二开重写版。

## 改动

- 改为调用秋枫白桦框架（maplebirch）的 Pet 接口渲染角色。
- 新增背景模式、透明空白裁边、换装实时更新、GIF 导出。
- 重写设置存储与面板，支持双存储与旧版迁移。
- 处理与框架桌宠的冲突，避免出现第二个小人。

## 依赖

- ModLoader `^2.31.2`
- TweeReplacer `^1.0.0`
- maplebirch `>=5.0.0`

## 说明

### 点击穿透并固定位置
勾选后模型不再阻挡点击事件，同时锁定模型位置禁止拖拽。

### 显示范围
- **完整**：显示完整画面。
- **仅特写**：裁掉左侧部分。
- **仅模型**：裁掉右侧部分。

### 前景背景
- **隐藏背景**：只显示角色模型。
- **显示背景**：显示侧栏画面（带背景）。

### 缩放倍率
调整显示大小，范围 50% ~ 100%。100% 就是画面自己的原始像素大小。

### 透明度
调整模型的不透明度，范围 10% ~ 100%。留了 10% 的下限，全透明会让你再也找不到它。

### 导出动作动图
把接下来 2 秒的画面逐帧采集成 GIF 下载。采的是当前模式正在显示的东西：
- 隐藏背景模式采角色模型；
- 显示背景模式采背景图（侧栏画面的拷贝）。

两种模式都按量出来的内容框裁掉四周的透明空白，导出大小与浮窗一致。游戏设置里开了侧边栏动画才会有动效，否则导出的是静止画面。
