# 小小PC-修复增强

> Litter-PC-Fix-Enhance

一个为 *Degrees of Lewdity* 打造的角色立绘模组

<img width="480" height="362" alt="微信图片_20261009222138_2_10" src="https://github.com/user-attachments/assets/ae520209-4dae-4d8a-a8ee-9b1f0e00906c" />


## 功能

- **模型开关**：显示 / 隐藏角色立绘
- **点击穿透并固定位置**：模型不再阻挡点击事件，同时锁定位置禁止拖拽
- **仅特写**：只显示特写区域
- **仅模型**：只显示模型区域
- **前景背景**：隐藏背景只显示模型，显示背景与模型
- **缩放倍率**：0.5 ~ 1.0，只允许缩小

> 「仅特写」与「仅模型」互斥，同时只能开启一个。

## 依赖

- ModLoader `^2.31.2`
- TweeReplacer `^1.0.0`
- maplebirch `>=5.0.0`

原小小PC模组仓库：https://github.com/ANLINSTUDIO/Degrees-of-Lewdity-DolLitterPC
