# 小小PC-修复增强 / Litter-PC-Fix-Enhance

基于原「小小PC」模组的二开重写版。

<img width="480" height="362" alt="微信图片_20261009222138_2_10" src="https://github.com/user-attachments/assets/ae520209-4dae-4d8a-a8ee-9b1f0e00906c" />

## 改动

- 处理与前景背景模组的冲突，本版可自由选择是否显示背景。
- 改为调用秋枫白桦框架（maplebirch）的 Pet 接口渲染角色。
- 新增显仅模型、仅特写、透明空白裁边、模型透明度、GIF 导出。
- 重写设置存储与面板，本地设置优先于存档副本，刷新、换存档不改变玩家偏好。

## 依赖

- ModLoader `^2.31.2`
- TweeReplacer `^1.0.0`
- maplebirch `>=5.0.0`
- 游戏版本 `>=0.5.11.9`

## 说明

### 点击穿透并固定位置
勾选后模型不再阻挡点击事件，同时锁定模型位置禁止拖拽。

### 显示范围
- **完整**：显示完整画面。
- **仅特写**：只显示特写框。
- **仅模型**：只显示PC模型。

### 前景背景
- **隐藏背景**：隐藏前景背景画布。
- **显示背景**：显示前景背景画布。

### 缩放倍率
调整显示大小，范围 50% ~ 100%。100% 就是画面自己的原始像素大小。

### 透明度
调整模型的不透明度，范围 10% ~ 100%。留了 10% 的下限，全透明会完全隐藏。

### 导出动作动图
把接下来 2 秒的画面逐帧采集成 GIF 下载。采的是当前模式正在显示的东西：
- 隐藏背景模式采角色模型；
- 显示背景模式采背景图（侧栏画面的拷贝）。

两种模式都按量出来的内容框裁掉四周的透明空白，导出大小与浮窗一致。游戏设置里开了侧边栏动画才会有动效，否则导出的是静止画面。  
部分手机浏览器不会自动触发 GIF 下载，iPhone需要使用结果行里的分享按钮保存到文件，否则会被iOS系统强制改为静止帧图片。
