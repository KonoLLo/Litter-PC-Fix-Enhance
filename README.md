# 小小PC-修复增强 / Litter-PC-Fix-Enhance

基于原「小小PC」模组的二开重写版。

## 改动

以当前版本 v1.8.4 为准：

- 处理与前景背景模组的冲突，可以自由选择是否显示背景。
- 在衣柜、镜子、商店换好衣服后，浮窗小人马上换成同一套。以前偶尔出现「侧栏已经是新衣服、小人还穿着上一套」，已经彻底解决。
- 小人偶尔会突然静止（呼吸、眨眼都停住），现在会自己重新跟上，不需要你做任何操作。
- 修好了秋枫白桦框架升到 5.4.6 之后浮窗小人掉头发的问题，发型与侧栏一致。
- 点击穿透、固定位置拆成两个独立开关，可以任意组合。勾了点击穿透之后，长按小人 0.45 秒仍然能把它拖走。
- 显示范围改成双向滑条：中点是完整，往右只留特写、往左只留模型。
- 缩放倍率 50% ~ 150%、透明度 10% ~ 100%，都带「重设」按钮。
- 导出动作动图：把接下来 2 秒的画面逐帧采集成 GIF 下载。
- 重写设置存储与面板，本地设置优先于存档副本，刷新、换存档不会改变玩家偏好。

## 说明

设置入口在游戏内「选项」面板的**小小PC**标签页里，各项名称与下面一致。

### 模型开关
勾选后在游戏界面上显示角色模型立绘。

### 点击穿透
勾选后模型整体不再阻挡点击，手指可以点到它下面的游戏按钮；代价是穿透期间直接拖不动小人，要长按才能挪。若万一小人压住了「选项」入口，先勾上它就能点到面板把它关掉，再拖走小人。与固定位置各自独立，可任意组合。

### 固定位置
勾选后锁定小人位置、禁止拖拽，避免误触挪动。与点击穿透各自独立，可任意组合。

### 当前位置
显示小人左上角的屏幕坐标，旁边是「重置位置」，一键回到默认停放点。

### 前景背景
- **隐藏背景**：只显示角色模型。
- **显示背景**：显示背景画布（侧栏画面的拷贝），用于和前景背景模组共存时按需选择。

两种模式都会按实际画出来的内容裁掉画布四周的透明空白，浮窗大小就等于那张画面本身。裁边靠读像素量出来，量不到（刚进局、画布还没画）时先按原来的正方形显示。

### 缩放倍率
调整显示大小，范围 50% ~ 150%。100% 就是画面自己的原始像素大小。「重设」回到 85%。

### 显示范围
双向滑条，中点是完整。往右是仅特写，从左往右裁、越往右裁得越多；往左是仅模型，从右往左裁、越往左裁得越多。数值是裁掉那一侧的百分比，0 就是完整，范围 −100 ~ 100。「重设」回到完整。与秋枫白桦框架的同名设置互不影响。

### 透明度
调整模型的不透明度，范围 10% ~ 100%。留了 10% 的下限，全透明会让你再也找不到它。

### 导出动作动图
把接下来 2 秒的画面逐帧采集成 GIF 下载。采的是当前模式正在显示的东西：

- 隐藏背景模式采角色模型；
- 显示背景模式采背景图（侧栏画面的拷贝）。

两种模式都按量出来的内容框裁掉四周的透明空白，导出大小与浮窗一致。游戏设置里开了侧边栏动画才会有动效，否则导出的是静止画面；导出结果与你摆放的位置、透明度无关。  
部分手机浏览器不会自动触发 GIF 下载，iPhone 需要使用结果行里的分享按钮保存到文件，否则会被 iOS 系统强制改为静止帧图片。
